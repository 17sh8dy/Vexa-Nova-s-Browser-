VexaBot

VexaBot is the web crawler for Vexa Search, the search engine Nova is building from scratch for the Vexa browser. Vexa Search is in beta. VexaBot visits public web pages so they can be found in search results.

How to recognise it

VexaBot sends this user agent with every request:

Mozilla/5.0 (compatible; VexaBot/0.1; +https://vexa.shadylabs.workers.dev/bot)

The robots.txt product token is VexaBot.

How it behaves

  • It reads and obeys robots.txt (RFC 9309), including Crawl-delay, and re-reads it at least every 24 hours. If your robots.txt returns a server error, VexaBot stays away until it can read it.
  • It requests one page at a time from each site, at least 1.5 seconds apart.
  • It respects noindex and nofollow in <meta name="robots"> and <meta name="vexabot">, the X-Robots-Tag header, and rel="nofollow" on links.
  • It downloads HTML only (up to 2 MB per page), never submits forms, never logs in and never runs scripts.
  • It does not crawl adult or pornographic websites.

Block or slow VexaBot

To keep VexaBot off your whole site, add this to your robots.txt:

User-agent: VexaBot
Disallow: /

To keep it out of part of your site:

User-agent: VexaBot
Disallow: /private/

To ask it to wait longer between requests (in seconds):

User-agent: VexaBot
Crawl-delay: 10

To keep a single page out of results, add <meta name="vexabot" content="noindex"> to it.
