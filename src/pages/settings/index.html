Spaces

Each Space has its own tabs in every window, and can have its own look, wallpaper, pinned sites and startup pages. Switch with the sidebar, the Command Center or Ctrl+Shift+1…9. An isolated Space also keeps its own cookies, logins and site storage — use it to be signed in to two accounts at once. Ordinary Spaces share one browser profile: they organize tabs, they are not a privacy boundary.

Focus & Reader

Focus sessions give one task its own Space, a timer and fewer distractions (start one from the sidebar, the menu or the Command Center: “focus on essay for 25 min”). The minimal interface (Ctrl+Shift+F) hides tabs, sidebar and bookmarks. Reader view (F9) shows just the article.

Sync

Vexa has no server. Sync keeps one end-to-end encrypted file in a folder you choose — put that folder inside OneDrive, Dropbox, Google Drive or Syncthing on each device and your bookmarks, passwords, autofill details and main settings follow you. History, tabs and downloads stay on each device.

Extensions

Load unpacked Chrome extensions (a folder containing manifest.json). Content scripts, background workers and storage work; toolbar popups and extension-managed tabs/windows are not supported by this engine yet. Only install extensions you trust — they can read the pages you visit.

Compatibility

How Vexa works with sites that are strict about which browser you use. The full explanation is in docs/COMPATIBILITY.md.

Google sign-in

Present the Chrome brand to GoogleGoogle's sign-in refuses browsers it can't recognise and has no way to register a new one. With this on, Vexa adds “Google Chrome” to the browser brands it reports (Client Hints) on Google's own sites only. Vexa is built on Chromium, the open-source engine of Chrome, but it is not Chrome, so this is a compatibility claim, not the full truth. Other sites always see the honest Chromium brands. Turn it off to never claim the Chrome brand; Google sign-in may then be refused.
“Sign in with Google” buttons on other sitesThose buttons run in a frame from accounts.google.com that needs your Google cookies. Vexa Shields blocks cross-site cookies, so it lets these through for that one sign-in address only. Turn off to block them too (the buttons then stop working).
