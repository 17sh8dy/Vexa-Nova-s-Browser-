Sync

Vexa has no server. Sync keeps one end-to-end encrypted file in a folder you choose — put that folder inside OneDrive, Dropbox, Google Drive or Syncthing on each device and your bookmarks, passwords, autofill details and main settings follow you. History, tabs and downloads stay on each device.

Extensions

Load unpacked Chrome extensions (a folder containing manifest.json). Content scripts, background workers and storage work; toolbar popups and extension-managed tabs/windows are not supported by this engine yet. Only install extensions you trust — they can read the pages you visit.
